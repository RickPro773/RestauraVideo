# RestauraVideo

RestauraVideo é uma ferramenta para restauração e compressão de vídeos para Windows.

## Status

🚧 Alpha

O projeto ainda está em desenvolvimento.

## Recursos

- Seleção de vídeos
- Análise de vídeo
- Conversão para MP4
- H.264
- AAC
- Compressão por tamanho
- Limite de tamanho configurável
- Qualidade de áudio configurável
- Qualidade de vídeo configurável
- Interface Dark/Light
- Atualizações automáticas
